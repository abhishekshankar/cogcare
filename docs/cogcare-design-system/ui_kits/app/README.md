# CogCare App UI Kit

## Overview
High-fidelity interactive prototype of the CogCare member dashboard and marketing site.

## Products Covered
- **Dashboard** — authenticated member area (Brain Credit, My Tests, More Tests, Consultations, Settings)
- **Login/Signup** — auth flow (sign in, create account, forgot password)
- **Homepage hero** — marketing homepage partial

## Design Direction
> "Earthy, rounded, glass kind of style. Trust is key."

The improved dashboard builds on the existing palette with:
- **Glassmorphic panels** — subtle frosted surfaces with forest-tinted shadows
- **Generous rounding** — 24–40px card radii throughout
- **Warmth-first hierarchy** — cream backgrounds, clay accents, forest green for data/authority
- **Trust signals** — clinical score display, institution credibility, clear data ownership

## Usage
Open `index.html` in a browser for the full interactive click-thru prototype.
